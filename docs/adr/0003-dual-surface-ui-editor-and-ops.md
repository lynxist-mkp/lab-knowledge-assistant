# ADR 0003: 编辑工作台与运维看板双面 UI

**Status:** accepted  
**Date:** 2026-08-27  
**Parent:** [双面 UI 规格 #1](https://github.com/lynxist-mkp/wenmai-assistant/issues/1)

## Context

早期交付把教程「六页 Dashboard」挂在根路径，默认入口是运维总览；视觉是临时 cream + teal。领域产品是面向融媒编辑的**福云·文脉助手**（**提问**须带出处或**拒答**），运维观测是另一类用户。grilling 后确认要两套面，并对齐福云内容库族蓝白，而不是再做一个混装后台。

## Decision

1. **双面**：默认 `/` 为**编辑工作台**；**运维看板**挂在 `/ops`（默认概览）。导航硬隔离，共享内容库族蓝白 token；辨识靠产品名与信息架构，不另做「闽派妆」。
2. **废旧根路径**：原 `/browse`、`/ingestion`、`/eval` 等 HTML **直接 404**，不重定向——只保留一套权威地图。
3. **仍用 Jinja2 SSR**：无前端构建、一条 `uvicorn`；不为此拆 SPA。JSON API 契约不变。
4. **库览归属**：完整**库览**只在运维；编辑仅出处页内只读抽屉。
5. **追踪**：运维侧六能保留，入库/查询 Trace 收成统一追踪（分 Tab）。

## Consequences

- 根路径不再是总览；书签旧 URL 会碎，换来入口语义正确。
- 编辑与运维可分票实现（先纸面与壳，再编辑，再运维）。
- 多轮对话明确延后，避免模糊**拒答**/出处边界。
